A Python-based AI assistant that understands natural-language requests and performs real actions on your behalf.

It can:

send emails using Gmail
create Google Calendar events
handle combined tasks such as “schedule a meeting and send the invite”
The app uses:

Groq for the language model
Gmail API for email sending
Google Calendar API for event scheduling
OAuth authentication for secure access
This project demonstrates autonomous tool calling in an LLM-based assistant, where the model decides what action to take and the Python code executes it in real time.# agentic-ai-s
